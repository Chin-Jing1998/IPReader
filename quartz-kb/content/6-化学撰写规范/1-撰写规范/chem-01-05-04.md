【释义】[[term-0385|保健食品]]，是[[term-0384|食品]]的一种，是指具有特定保健功能或者以补充维生素、矿物质为目的的食品。

即保健食品适宜于特定人群食用，具有调节机体功能，不以治疗疾病为目的，并且对人体不产生任何急性、亚急性或者慢性危害的食品，例如，无毒，不能有副作用。

5.4.1. 要核实专利申请所对应的保健食品是否有在药监局的[[term-0623|备案信息]]（可请教客户，或自行查询），如果备案信息没有公开该产品配方，则可同时保护产品和制备方法，若备案信息公开了产品配方，而配方是常规的，则[[term-0193|申请文件]]应以制备方法为主，重点体现制备方法的创新性

5.4.2. 具有特定保健功能的保健食品保健食品的原料和/或组分，应当符合食品安全法的要求，具体为：严禁使用有毒、有害、霉变、过期物质，禁用物质；

应当在药食两用的名单和保健食品可用物品名单之内；

如果原料和/或组分既不属于禁用原料，也不在药食同源原料名单中，则应在[[term-0453|说明书]]中提供安全性数据，否则有可能不符合A5的规定（[[term-0507|妨害公共利益]]）[[term-0702|技术主题]]的命名根据食品安全法的规定，保健品的功能不应包括“预防” 和“治疗”，因此[[term-0892|权利要求]]中不应存在措词“预防和/或治疗”。但是对于说明书中的类似措词不做要求，因为专利权保护的是权利要求请求保护的[[term-0432|技术方案]]，说明书中记载但未在权利要求中请求保护技术方案可以不予考虑保健品的功能范围共计27 种，因此权利要求[[term-0297|主题名称]]需要符合这27 种的规定，如不能写成“降血压”，应当写成“辅助降血压”。因为保健品不是药品，虽然能调理生理功能，但是对治疗疾病效果不大，只能用来进行辅助治疗

保健食品的效果鉴于保健食品不具有“预防”和“治疗”的功能，因此不能采用目的在于预防或治疗病症的临床病例来表明效果，而应侧重于检测那些能反映相关改善项目的参数，用这些参数的变化情况来反映效果

【正确示例】动物实验，采用小鼠负重游泳实验，研究保健食品缓解体力疲劳的作用，实验如下：采用小鼠作为受试动物，取40 只小鼠，雌雄各半，体重为 18～22g，随机分为 4 组：[[term-0016|实施例]]一的低、中、高剂量组和对照组，每组 10 只。实施例一的片剂，人体服用剂量是每天2次，每次1片，成人体重按 $6 0 \ k g$ 计，折合剂量 0.02g/kg·bw，低、中、高剂量组，剂量分别为 0.1、0.2、0.6/kg·bw(分别相当于人体服用剂量的 5、10、30 倍)。低、中、高剂量试液配制时，分别称取 1、2、6g实施例一的片剂加蒸馏水至 200mL，对照组予以等体积蒸馏水，每天灌胃 l 次，灌胃体积为 0.2mL/10g·bw，连续 30 天。分别给予药粉(将药片粉碎并研细) $) 2 . 0 9 / \mathsf { k g }$ 灌胃，连续给药 20 天。末次给小鼠受试物 30min 后，置于游泳箱中游泳，水深约 30cm，水温 $2 5 ^ { \circ } \mathsf { C } \pm 1 . 0 ^ { \circ } \mathsf { C }$ ，鼠尾根部负荷 $5 \%$ 体重的铅皮。记录小鼠自游泳开始至死亡的时间作为负重游泳时间(s)。游泳时间为计量资料，若受试物组游泳时间明显长于对照组游泳时间，且差异有显著性 $\scriptstyle ( \mathsf { P } \< 0 . 0 5 )$ ，可判定该受试物有延长小鼠负重游泳时间的作用。结果见表1。

人体实验，研究保健食品缓解体力疲劳的作用，实验如下：一、实验对象与方法

1、实验对象：以某体育学院 30 名男子长跑运动员(平均年龄 $2 0 . 8 \pm 0 . 6 5$ 岁)为研究对象。

2、实验分组分组：30 名受试者随机分为3组；

空白组 $( \mathsf { N } = 1 5 )$ )服用安慰剂，2片/天；

对照组服用含红景天提取物0.22g，含刺五加提取物0.18g 的[[term-0074|组合物]]；

实验组服用本发明的缓解体力疲劳片组(实施例一制备的缓解体力疲劳的保健食品，每片含枸杞子提取物 0.175g，含红景天提取物0.11g，含刺五加提取物 $0 . 0 9 { \tt g } ) 2$ 片/天；

各组均连续服用8周，整个实验期间，禁服其他缓解体力疲劳的食品和药品。

3、实验方法要求受试者在实验前空腹来到实验室取安静时静脉血，运动前进行运动负荷(在 Monark 功率计上运动)，先作准备活动 1min(0 负荷)，然后以 50W 功率开始，逐步递增负荷，3 分钟左右达到 70％Hrmax(由预试验测定得出)，此后即不再增加负荷量，持续蹬车 60 分钟。运动中心率采用 Polar 表监测，控制实验室的气温及湿度。受试者在服用8周各组规定的保健品后，再次进行测试。

4、指标和方法测试指标：运动中每半小时取耳血1 次，测乳酸。运动后即刻、运动后第3、9、15分钟测量恢复心率，取耳血测乳酸。

5、结果统计数据处理采用 SPSS10.0 软件，所有数据用均值±标准差来表示，采用方差及配对T检验方法。
